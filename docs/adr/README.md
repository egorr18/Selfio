# ADR (Architecture Decision Records)

ADR — це короткі записи “чому ми зробили таке рішення”.

## Як читати
- 0001, 0002… — порядок рішень.
- У кожному ADR є: Context → Decision → Consequences.

## Як додавати новий ADR
1) Створи файл `docs/adr/000X-<short-title>.md`
2) Заповни шаблон
3) Закоміть

## Template
- Status: proposed | accepted | deprecated
- Context: що було, яка проблема
- Decision: що вирішили і як
- Consequences: плюси/мінуси/ризики
- Alternatives: що розглядали
